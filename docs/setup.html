くらぶボット

くらぶのツールの知らせを、自分のボットで受けとる（確かめ中）

くらぶ（Qlove）のツールの知らせを、LINE で受けとるボットを、自分で1つだけ持てます。どのツールも、この1つのボットにつなぎます。

  • 🍚 しょくじ：食べたものの名前を送ると記録して、1日の合計カロリーを返します。くわしく入れるのは しょくじ の画面で
  • 📝 記録：「# coding」のように # を付けて送ると記録します。つづく（習慣カレンダー）とつながり、GitHub の草にもできます
  • ☁️ 天気（そらくる）：雨・気圧の変化・気温の大きな変わり目がある日だけ、決めた時間に知らせます。気圧の目安は、そらくると同じ見方です

これから、記念日（くろのす）・節目（すくすく）・旅（ゆくさき）なども、このボットに足していく予定です。使わない機能は、シートの「機能」で切れます。

ボットも、鍵も、記録も、ぜんぶあなたのものです。くらぶは何も預かりません。お金はかかりません（LINE の無料のプランで、月200通まで送れます。全部の機能で分け合います）。

用意するもの（30分くらい）

  • パソコン（スマホでもできますが、パソコンのほうが楽です）
  • Google のアカウント（Gmail のアカウント）
  • LINE のアカウント（ふだん使っているもの）

1LINE の公式アカウントを作る

  1. LINE公式アカウントのはじめかたを開き、「LINE公式アカウントをはじめる」→ 自分の LINE でログイン
  2. アカウント名（例：わが家のくらぶ）・業種（「個人」など）を入れて作る

Messaging API を使えるようにする

  1. LINE Official Account Manager を開き、作ったアカウントを選ぶ
  2. 右上の 「設定」（歯車）→ 左の列の 「Messaging API」→ まん中の 「Messaging APIを利用する」
  3. プロバイダーを選ぶ（はじめてなら、新しく名前を入れる。例：自分の名前）→「OK」

あいさつ・自動の返事を止める

  1. 同じ「設定」の左の列の 「応答設定」
  2. 「応答メッセージ」をオフ、「Webhook」をオン（「あいさつメッセージ」もオフにすると、ボットのあいさつだけになります）

チャネルアクセストークンをもらう

  1. LINE Developers コンソールを開き、同じ LINE でログイン
  2. さっきのプロバイダー → アカウントの名前（チャネル）を選ぶ
  3. 上のタブの 「Messaging API設定」→ いちばん下の 「チャネルアクセストークン（長期）」の 「発行」
  4. 出てきた長い文字をコピーしておく （人に見せない。見られたら「再発行」）

2配布用シートをコピーする

  1. 配布用シート（くらぶボット）を開き、「コピーを作成」（シートについたプログラム（GAS）の入口も一緒にコピーされます。中身はライブラリ「QloveBot」を読みます。地点・使う人などは、このシートに残ります）
  2. コピーしたシートの上のメニューの 「拡張機能」→ 「Apps Script」
  3. 左の列の 歯車（プロジェクトの設定）→ いちばん下の 「スクリプト プロパティを追加」
    • プロパティ：LINE_CHANNEL_ACCESS_TOKEN
    • 値：1 でコピーした長い文字
    →「スクリプト プロパティを保存」
  4. 左の列の 「<>（エディタ）」→ 00_setup.gs を開く → 上の関数を選ぶところで setupBot → 「▶ 実行」
    はじめは「権限を確認」が出ます：自分のアカウントを選ぶ →「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」。自分で作ったプログラムなので、ほかの人には届きません。Google ドライブの許可は、しょくじで送った食事の写真を、自分のドライブに置くためです

3ウェブアプリとして公開して、LINE とつなぐ

  1. 右上の 「デプロイ」→ 「新しいデプロイ」→ 左の歯車（種類の選択）→ 「ウェブアプリ」
  2. 次のユーザーとして実行：自分／アクセスできるユーザー：全員 →「デプロイ」（LINE から呼べるように「全員」にします。合言葉が合わない呼び出しは何もしません）
  3. エディタにもどり、showWebhookUrl を「▶ 実行」→ 下の「実行ログ」の ① の URL（…/exec?key=…）をコピー （人に見せない。② の合言葉なしの URL は、あとでツールに入れるもの）
  4. LINE Developers コンソールの 「Messaging API設定」タブ →「Webhook設定」の 「Webhook URL」の「編集」→ 貼る →「更新」→「検証」で「成功」と出ればよい
  5. その下の 「Webhookの利用」をオン

4友だちになって、持ち主になる

  1. 同じ「Messaging API設定」タブのいちばん上の QR コードを、スマホの LINE で読んで友だちになる
  2. ボットから「👋 ようこそ」が届いたら、下の 「🔑 持ち主の登録」を押す
  3. 10分以内に、エディタで adoptOwner を「▶ 実行」→ 実行ログに自分の名前が出ればよい
  4. トークの下のメニューも作るなら、setupRichMenu を「▶ 実行」（上のタブで「しょくじ」と「Qlove」を切りかえ。天気・記録は「Qlove」のタブに）

5ためす

  1. トークで #テスト と送る → 🧪 のカード。「🧪 🍚 しょくじの見本」「🧪 ☁️ 天気の見本」などで、届くカードの見本が見られます（持ち主だけ。見本はシートに書かず、無料の枠も使いません）
  2. 「🩺 自己点検」で、準備がそろっているかを見る（❌ があれば、その行のとおりに直す）
  3. 🍚 しょくじ：トークで食べたものの名前（例：カレーライス）を送る → 記録して、きょうの集計が返ります。くわしく入れるのは、メニューの「朝」「昼」などから開く しょくじ の画面で
  4. 📝 記録：# coding のように、先頭に # を付けて送る → 記録します。+15 で、いま記録したものに15分足します
  5. ☁️ 天気：「Qlove」のタブの「天気の知らせ」→「📍 地点を足す」→「📍 位置情報を送る」で場所を送る →「⏰ 21時（明日のぶん）」などで時間を選ぶ

# も 📍 も付いていない文は、食べたものの名前として記録します（しょくじを使わないときは、シートの「機能」で meal を FALSE に）。

知らせは、決めた時間の数分あとに届きます（1時間おきに見ています）。何もない日は届きません。しょくじの20時の知らせは、受けとると決めた人だけ（「🍚 しょくじ」のクイックリプライ「🔔 20時に知らせてもらう」）。

📝 記録の書き方

トークで、先頭に # を付けて送ります（全角の ＃ でもよい）。持ち主の記録は、GitHub につないでいれば草にもなります。

ふだんの記録

  • # coding・# 💪workout・# 読書 … したことを記録（名前は自由。「ジム」→ workout のような言いかえは、シートの action_aliases）
  • +15 … いま記録したものに15分足す（カードの［+15分］［+30分］［+60分］でも）

はじめる・おわる（充電など、時間をはかるもの）

  • # s charge 20% → # e charge 85% … はじめとおわりの時刻から時間を出す。後ろの文字（20% など）はメモ（「75% → 85%（+10%）」のように出る）
  • ショートカットから送るときは、行に分けた形でも： 
    # COMMAND
command: battery
icon: 🔋
label: Battery
type: start
memo: 75%
    type は start（はじめ）か end（おわり）。command が同じものどうしを組にする。label が Battery・charge なら「充電」と出す

出退勤

  • # attendance start（出勤）→ # attendance end（退勤）。# COMMAND の形で command: attendance でもよい
  • # REPORT attendance … 今月の出勤・退勤の時刻

移動（CarPlay）

  • iPhone のショートカット（オートメーション「CarPlay に接続したとき」「切断したとき」）で、このボットのトークに送る： 
    # trip
source: carplay
type: start
    おわりは type: end。位置（lat:・lng:）を入れると距離と速さも出す（位置は GitHub には書かない）
  • # REPORT trip … この7日の移動

記録の種類ごとの決まり（シート「log_actions」）

1行に1つの行動（coding・battery など）。持ち主がシートで直すと、次の記録から変わります（コードは直さなくてよい）。

  • label・icon … カードに出す名前と絵文字（例：battery → 🔋 充電）
  • github … 持ち主の記録を GitHub の草に送るか
  • stats … カードの数（きょう◯件・今週◯件・つづいて◯日）に入れるか
  • remind … 記録がない日の知らせで「した日」に数えるか（移動・出退勤・充電は、はじめから FALSE）
  • enabled … FALSE にすると、その行は使わない。行がない行動は、ふつうの記録（どれも TRUE と同じ）
  • type … 記録の型：time（はじめ〜おわりの時間）・place（時間と移動の距離）・value（時間と数値の差。例：充電の％）・空（ふつうの記録）
  • daily・goal・unit … 1日のまとめ方（sum 合計・count 回数・max いちばん大きい）と、○になる数（その日のまとめが goal 以上。空なら記録があれば○）と単位。例：study・time・sum・30・分 → 30分以上で○

型のある記録は、カードに「🎯 きょう 2時間5分／目標 30分 ✅」と出て、つづく（LINE の中）では習慣の名前のとなりに、きょうの合計が出ます。日をまたいだ記録は、はじめの日に数えます。はじめから12時間たっても「おわり」が来ないときは、12時間でおわりにして、1回だけ知らせます。

はじめて記録したときに、前の LOgBOT と同じ決まりの行を入れて作ります。「ジム → workout」のような言いかえは、シート「action_aliases」です。

ふりかえり・目標

  • # REPORT … どのふりかえりを見るか選ぶ／# quest … きょうと今週の目標

知らせ（持ち主だけ）

  • # 通知 … 記録がない日の知らせの時刻・送り方を、ボタンで変える（はじめは毎日20時。「まだのときだけ」「日曜に週のふりかえり」「止める」も）。# 通知 ためす で見本
  • # 設定 … いまの設定（知らせ・つづく・GitHub）を見る
  • 知らせに出る習慣は、つづくで「送る文」（例：# 💪workout）を決めたもの。つづくを LINE の中で開くと、ボットが覚えます

Alfred（Mac から記録）

  • このボットの URL（showWebhookUrl の ②）に、本文 {"sourceApp":"alfred","secret":"合言葉","text":"# coding"} を POST。合言葉はスクリプト プロパティの ALFRED_SECRET。持ち主の記録になります（返事は来ません）

家族や友だちにも使ってもらう

  1. QR コードを渡して、ボットの友だちになってもらう
  2. 相手が「🙋 使いたいと伝える」を押すと、持ち主に知らせが届く →「✅ 許す」
  3. グループに入れると、グループにも送れます（地点を足せるのは、持ち主と許した人だけ）

やめてもらうときは、メニューの「Qlove」のタブの「👥 使う人」→「🚫 名前」。その人が入れた知らせ（天気の地点など）も止まります。

くらぶのツールとつなぐ

しょくじ・つづくを LINE の中で開くと、記録がこのボットにも入り、ボットで入れた記録も画面に出ます（ブラウザで開いたときは、端末の中だけ）。

  1. LINE の中で しょくじ（メニューの「朝」など）・つづくを開き、下のほうの「⚙️ くらぶボットとつなぐ」に、showWebhookUrl の ② の URL（合言葉なし）を入れる
  2. それで記録が入れば終わりです。つながるのは、このボットの持ち主と、持ち主が許した人だけです

ツールは、LINE が出す本人の確かめ用の印だけを送ります。URL を知られても、使う人の呼び出ししか受けません。

前のボット（食事記録・LOgBOT）から引っこす

前のボットの記録は、そのまま使えます。シートのタブを写して、鍵を入れなおします。

  1. 前のボットのシートで、タブを右クリック →「コピー先」→「既存のスプレッドシート」→ くらぶボットのシート。写したタブの名前を、下のとおりに直す
    • 食事記録：users → meal_users、meal_logs・nutrition_master はそのまま
    • LOgBOT：logs・action_aliases はそのまま、users → log_users
    （前のシートは消さずに残しておく）
  2. エディタの「プロジェクトの設定」→「スクリプト プロパティ」に、使うものだけ入れる：GITHUB_TOKEN・GITHUB_OWNER・GITHUB_REPO（記録を GitHub の草にも）、ALFRED_SECRET（Alfred から記録する合言葉）、MEAL_DRIVE_FOLDER_ID（食事の写真を置くフォルダ。なければマイドライブ）
  3. LOgBOT の記録：前のボットの持ち主の ID（前のスクリプト プロパティの user_id と LIFF_USER_ID）を、LOG_OLD_OWNER_IDS に「,」区切りで入れる → moveOldLogRecordsPreview で件数を見て、moveOldLogRecords で付けかえる
  4. つづく・しょくじ（LINE の中）で、このボットの URL（showWebhookUrl の ②）を入れ、メニューの「Qlove」→「できること」→「🔗 ツールとつなぐ」の番号を入れる
  5. Alfred の送り先を、このボットの URL（② の URL）に。CarPlay のショートカットの送り先を、このボットのトークに
  6. 家族には、このボットを友だちに足してもらい「🙋 使いたいと伝える」→「✅ 許す」

LINE の「だれか」の番号は、LINE Developers のプロバイダーごとにちがいます。前のボットと同じプロバイダーのアカウントなら、家族の食事の記録はそのまま合います。

新しい版にするとき

エディタの左の列の 「ライブラリ」の QloveBot を押す → 「バージョン」をいちばん新しいものに →「保存」。シートや設定は、そのまま使えます。

版は checkBot の実行ログのいちばん上に出ます。

知っておくこと

  • 使わない機能は、シートの「機能」の enabled を FALSE にすると止まります
  • 天気は Open-Meteo（無料・商用でない使い方だけ）から、地名は国土地理院から読みます。お店や会社の宣伝・有料のサービスには使わないでね
  • 今月の送った数が上限の8割をこえたら、知らせを止めます（月が変わると、また届きます）
  • 気圧は天気予報から出した「変化の目安」です。体調の予測や診断ではありません
  • うまく動かないときは、シートの「動作の記録」と、エディタの checkBot の実行ログを見てください
  • やめるときは、エディタの「デプロイ」→「デプロイを管理」でアーカイブし、左の列の「トリガー」（時計）で hourlyQloveBot を消します
